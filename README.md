# Nergora Enterprise — İmza Uygulaması (Binary Dağıtım)

Bu depo yalnızca kurulum ikililerini (binary) yayınlar. Uygulamanın kaynak kodu bu depoda bulunmaz.

## Sürümler

Kurulum dosyalarına **Releases** bölümünden ulaşın.

## Kurulum (macOS, Apple Silicon)

1. `Nergora-Enterprise-<sürüm>-arm64.dmg` dosyasını indirin.
2. DMG'yi açıp uygulamayı `Applications` klasörüne sürükleyin.
3. Uygulama henüz Apple notarization'dan geçmediği için ilk açılışta Gatekeeper uyarısı verebilir:
   uygulamaya sağ tıklayıp **Aç** seçin (veya Sistem Ayarları → Gizlilik ve Güvenlik → **Yine de Aç**).

## Windows

Windows kurulumu henüz yayınlanmadı; Windows/CI ortamında üretilecektir.

## Doğrulama

Her sürümün SHA-256 özetleri ilgili release notlarında yer alır.
